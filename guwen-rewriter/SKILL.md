# guwen-rewriter — 白话变古风意境美句

## 使命

把一句"人人都懂的大白话"，改写成古风意境短句——**字面雅致、画面感强、读来有韵味，但意思和原句完全一致**。不是掉书袋、不是堆典故、不是曲解原意，而是用传统的意象与句式，把同一层意思说得更好看。

核心原则只有一条：**意思一致是硬约束，意境优美是追求目标**。宁可朴素通顺，不可为了"古"而歪曲原意。

## 何时调用此 skill

用户出现以下意图时触发：
- "帮我把这句话改成古风/古文/文言"
- "这句话太白话了，写得好听点/有韵味点"
- "给我来个朋友圈古风文案/诗意表达"
- "把这句 slogan/座右铭/情话雅化一下"
- 给出"白话 → 古风"的配对需求，如用户提供的范例语料

**不做什么**：
- ❌ 古文到白话的翻译、逐字训诂（方向反了）
- ❌ 写一整篇文言文议论文/书信（本 skill 只做"句子/短句"层面的改写）
- ❌ 为追求文采擅自改变原意（这是红线，见质量红线）

## 核心方法论：五步转换流水线

拿到一句白话后，**严格按顺序**走完五步。每步都要在心里完成，再落笔。

### 第 1 步 · 解意（Decode）

先把白话"拆干净"，提取四要素：
- **主体**：谁/什么（我、人、时光、缘分……）
- **情境**：发生了什么或处于什么状态
- **情绪/态度**：原句带什么底色（豁达、淡泊、坚定、释然、欢喜……）
- **深意**：这句话真正想"说给听者"的那层意思（往往比字面深一层）

> 例：「世界喧闹，做自己就好」
> 主体=人；情境=外界嘈杂；情绪=不在乎外界；深意=守住本心，不必迎合。

### 第 2 步 · 定调（Tone）

从 `references/imagery.md` 的「意境类型库」里选 1 个最贴合的基调。基调决定整句的"气味"：
缘分淡然 / 做自己 / 淡泊自在 / 安然从容 / 欢喜日常 / 平静知足 / 岁月静好 / 不忘初心 / 释怀过往 / 随遇而安。

> 上例「做自己就好」→ 基调=**做自己**。

### 第 3 步 · 选象（Imagery）

按基调，从意象库挑 2–4 个意象，讲究"自然物 + 心境词"的搭配：
- 自然物（画面）：山海、风雨、风、花、月、云、星河、烟火、清浅、流年
- 时间词：时光、岁月、流年、经年、岁华、煮雨、缝花
- 心境词：花田、素心、清欢、安然、欢喜、温润、淡泊、清简、诗意、本心

> 选象：风（听风知世）、人间（喧闹世相）、本心。

### 第 4 步 · 炼句（Phrase）

套用 `references/imagery.md` 的「句式模板库」。**优先用对仗/并列句式**——两句一组最出韵味。可一次给 1–3 个变体：
- **对仗版**（最稳，两句平行，如"手持烟火以谋生，心怀诗意以谋爱"）
- **短句版**（一字/四字格，适合签名、标题）
- **雅致版**（略长，画面铺陈，适合朋友圈长文案）

> 对仗版：「听风千百遍，方知是人间」——外面再吵，听进去也不过是人间风声，做自己便是。

### 第 5 步 · 校验（Verify）

落笔后逐条核对，任一不过则回炉：
1. **意思一致**：把古风句反译回白话，是否等于原句？差一点都不行。
2. **意境到位**：读起来有画面、有余味，不干巴巴。
3. **自然通顺**：不拗口、不堆砌、不滥用生僻字。
4. **无硬伤**：不出现时代错乱的用词（如宋词里冒出"地铁"）；不用典出错。

## 输出格式

每次改写，**先给古文，再给一行"表达"**，用现代话把原意复述一遍，作为"意思一致"的证据。多版变体用分隔标出。

```
古文：<改写后的句子>
表达：<用现代白话把原意说清，证明没跑题>

—— 变体 ——
对仗版：……
短句版：……
雅致版：……
```

若用户只给了一句白话没指定风格，默认给「主句 + 1–2 个变体」。若用户给了范例风格（如"要山海自有归期那种"），优先对齐该风格。

## 质量红线（违反则重做）

1. **原意不可改**：古文句反译回白话必须≈原句。这是最高优先级，文采让位于它。
2. **不堆砌典故**：能用常见意象说清就不用生僻典；本 skill 面向大众，不是写骈文。
3. **不对仗硬凑**：对仗的两句必须"词性相对、意思相关"，不可为了对称而拼凑。
4. **不 modern 混古**：改写结果里不能夹现代词（"内卷""emo""打工人"），除非用户明确要求混搭风。
5. **每句可独立成立**：给出的每个变体都应是完整、可读、可单独使用的句子。

## 调用惯例

- **先吃透原意再动笔**：宁可多问一句"你这句话最想强调哪点"，也别改成另一个意思。
- **少即是多**：一句白话通常 1 个主句 + 至多 2 变体足够；别给七八句让用户挑花眼。
- **对齐用户范例**：用户若贴了喜欢的古风句，先模仿其句式与意象再扩展。
- **遇歧义先澄清**：白话若有双关/多解，选最稳妥的一种改写，并在"表达"里说明取的是哪种解。
