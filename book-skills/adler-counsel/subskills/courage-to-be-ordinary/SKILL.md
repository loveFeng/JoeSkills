# 甘于平凡的勇气 (Courage to Be Ordinary)

## R — 原文 (Reading)

> 阿德勒心理学非常重视的"甘于平凡的勇气"。为什么非要"特别"呢? 这是因为无法接受"普通的自己"。所以, 在"特别优秀"的梦想受挫之后便非常极端地转为"特别差劲"。但是, 普通和平凡真的不好吗? 实际上谁都是普通人。没有必要纠结于这一点。
>
> — 岸见一郎, 《被讨厌的勇气》第五夜

---

## I — 方法论骨架 (Interpretation)

人常以"特别优秀"为目标, 受挫后极端转为"特别差劲"——二者目的相同:**成为"特别的存在"、引起关注**。中间健康的"普通"被嫌弃。

阿德勒给的出路是**甘于平凡的勇气**:
- 普通 ≠ 无能, 没必要炫耀优越性, 也没必要羞耻于平凡。
- 这是 `self-acceptance` 的重要一步——接纳"普通的自己"。
- 拒绝"廉价优越性追求": 问题行为(逃学/割腕/吸烟)、闭门不出, 都是"不付出健全努力也要成为特别存在"的廉价手段。拿破仑式远大目标并非必需, 认真过好普通当下即可(`live-in-the-now`)。

## A1 — 书中的应用 (Past Application)

### 案例 1: 青年抗拒"甘于平凡"
- **问题**: 青年认为"甘于平凡"是肯定懒惰、扼杀天才。
- **方法论的使用**: 哲人点破青年把"普通"理解成"无能"; 普通≠无能, 无需特意炫耀优越性。
- **结论**: 拒绝普通的你, 是把普通当无能。
- **结果**: 引向自我接纳。

### 案例 2: 问题行为的"廉价优越性追求"
- **问题**: 青年不解为何孩子问题行为不停。
- **方法论的使用**: 哲人: 无论"特别优秀"还是"特别差劲", 目的都是"引起关注、成为特别存在"; 问题行为(扔橡皮/逃学/割腕)是**不付出健全努力**也能被关注的廉价手段。
- **结论**: 与"复仇"(报复父母)易相连。
- **结果**: 接 `life-lies` 与 `inferiority-triad`。

### 案例 3: 拿破仑式目标质疑
- **问题**: 青年以拿破仑/爱因斯坦必须"远大目标"反驳。
- **方法论的使用**: 哲人: 人生需要的是认真过好当下, 而非必须惊天动地。
- **结论**: 甘于平凡也能充实。
- **结果**: 接 `live-in-the-now`。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 因"平凡/普通"而羞耻, 觉人生无意义。
2. 在"必须出人头地"与"破罐破摔(特别差劲)"间摇摆。
3. 用问题行为/自我放弃来"引起关注"。

### 语言信号
- "我不想平庸""我必须出人头地"
- "平凡有什么意义""凭什么我是普通人"
- "特别差劲/破罐破摔""拒绝普通"

### 与相邻 skill 的区分
- 与 `self-acceptance` 区别: 自我接纳是"接受真实的60分"; 甘于平凡是接纳后具体放下"必须特别"的执念。本 skill 是接纳在"卓越焦虑"上的应用。
- 与 `live-in-the-now` 区别: 平凡处理"对平凡的羞耻"; 当下处理"对此时此刻的聚焦"。常连用(认真过普通当下)。

## E — 可执行步骤 (Execution)

1. **指认"特别"钟摆**
   - 完成标准: 用户说"必须特别/平凡无意义/破罐破摔", 标记为特别优秀↔特别差劲钟摆。

2. **拆解"普通=无能"误读**
   - 完成标准: 澄清普通≠无能, 人人皆普通, 无需羞耻也不必炫耀。

3. **识别廉价优越性追求**
   - 完成标准: 若用户用问题行为/自我放弃引人关注, 点明其"不付出健全努力也要特别"的本质, 引向 `life-lies`。判停条件: 若涉自伤, 先专业干预。

4. **练习甘于平凡 + 认真当下**
   - 完成标准: 鼓励用户在普通日常里认真跳舞, 接 `self-acceptance` 与 `live-in-the-now`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 真实需要追求卓越的领域(竞技体育、科研突破): 追求优秀非"情结", 勿强读为"必须平凡"。
- 用"平凡"当放弃一切努力的借口。

### 作者在书中警告的失败模式
- 廉价优越性追求: 问题行为/特别差劲, 只为成为"特别的存在"(第五夜)。

### 作者的盲点 / 时代局限
- 对身处真实上升通道受限环境者, "甘于平凡"可能被视为对结构性不公的安抚。

### 容易混淆的邻近方法论
- 甘于平凡 ≠ 躺平(仍认真过当下) ≠ 放弃卓越追求(在真需领域)。
