# 自我接纳 (Self-Acceptance)

## R — 原文 (Reading)

> 没必要特别积极地肯定自己, 不是自我肯定而是自我接纳。自我肯定是明明做不到但还是暗示自己说"我能行", 是对自己撒谎的生活方式。而自我接纳是指假如做不到就诚实地接受这个"做不到的自己", 然后尽量朝着能够做到的方向去努力, 不对自己撒谎。
>
> — 岸见一郎, 《被讨厌的勇气》第五夜

---

## I — 方法论骨架 (Interpretation)

关键区分:
- **自我肯定** = 对做不到的自己撒谎说"我能行"(易导致优越情结, 是谎言)。
- **自我接纳** = 诚实接受"60分的自己", 然后思考"如何接近100分", 不骗自己。

操作上套用"尼布尔祈祷文": 分清**能改变的**与**不能改变的**——接受不能更换的"这个我"(被给予的东西), 对能改变的事拿出改变的勇气。哲人称之为"肯定性的达观"。

自我接纳是共同体感觉三件套的第一环: 只有接纳真实自我, 才能不惧背叛地去`trust-others`, 进而`contribution-happiness`。

## A1 — 书中的应用 (Past Application)

### 案例 1: 60分与100分的比喻
- **问题**: 青年把"自我接纳"误解为更积极的自我肯定。
- **方法论的使用**: 哲人用60分比喻——自我肯定是对60分说自己"其实能得100分"(撒谎); 自我接纳是诚实接受60分, 努力思考"如何接近100分"。
- **结论**: 毫无缺点的人不存在, 要"积极承认"这一点。
- **结果**: 连接"肯定性的达观"与勇气。

### 案例 2: 尼布尔祈祷文
- **问题**: 青年觉得"达观"太消极。
- **方法论的使用**: 哲人引"赐我平静接受不能改变的, 赐我勇气改变能改变的, 赐我智慧分辨二者"。
- **结论**: 自我接纳=接受不能改变的"我" + 对能改变的拿出勇气。
- **结果**: 青年领悟"勇气"二字的重量。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 因某次失败/某特质而全面否定自己("我太差了")。
2. 用"我要变强/我能行"强行打气却内心不买账。
3. 卡在"接受现状"与"努力改变"的两难, 既不放过自己也不行动。

### 语言信号
- "我太差了""我接受不了这样的自己"
- "我必须变强""为什么我做不到"
- "假装积极没用""接纳自己但很丧"

### 与相邻 skill 的区分
- 与 `courage-to-be-ordinary` 区别: 自我接纳是"接受真实的60分"; 甘于平凡是接纳后进一步放下"必须特别"的执念。常连用。
- 与 `contribution-happiness` 区别: 接纳是"对自己诚实"; 贡献是"通过有用感体会价值"。先接纳才有贡献。

## E — 可执行步骤 (Execution)

1. **指认"自我肯定"式谎言**
   - 完成标准: 用户说"我能行"但无对应行动/信念, 标记为自我肯定式自我欺骗。

2. **拆成"能改变/不能改变"**
   - 完成标准: 帮用户列两栏——不可更换的(出身、部分特质、过去) vs 可努力的(行为、态度、下一步)。

3. **诚实接受 + 朝能做的努力**
   - 完成标准: 对"不能改变"说"我接受"; 对"能改变"问"今天能做什么接近100分?" 判停条件: 若用户用"接纳"当彻底放弃的借口, 回到"朝能做的努力"这一半。

4. **落到"此时此刻"的一小步**
   - 完成标准: 给出今天可执行的一件小事, 接 `live-in-the-now`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 重度抑郁、自伤危机: 先专业干预, 勿用"接纳"做心理自助。
- 用"接纳"合理化彻底躺平、放弃所有能改变的事。

### 作者在书中警告的失败模式
- 自我肯定式谎言: 对做不到的自己强行说"我能行", 走向优越情结(第五夜)。

### 作者的盲点 / 时代局限
- "接受不能改变的"可能低估某些结构性困境的可改变空间, 需配合现实行动而非纯心理接纳。

### 容易混淆的邻近方法论
- 自我接纳 ≠ 自我肯定(撒谎) ≠ 自暴自弃(放弃能改变的)。
